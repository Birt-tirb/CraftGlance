# CraftGlance project images

The three numbered PNGs are the user's supplied in-game screenshots, copied
without cropping, retouching, resizing, or changing their contents.

| File | View |
| --- | --- |
| 01-this-recipe.png | Linen Bandage beside First Aid: Craft now 4, Known stock 14, character holdings and scan status. |
| 02-material-search.png | All Materials searched for linen, with recorded stock by character. |
| 03-all-materials.png | The longer recorded reagent list beside Cooking. |

Starred bank quantities (for example 0* or 11*) are last observations marked for
rescan. They are displayed for reference and excluded from Known stock until
successfully rescanned. Not scanned identifies an unknown inventory.

`craftglance-icon.png` is the original project icon: a square 1254 x 1254 PNG,
created with built-in image generation for this project. The exact generation
prompt and provenance are in `../curseforge/icon-prompt.txt`. It does not reuse
any screenshot pixels, game icon, or existing logo.
